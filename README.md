# Find Your Dream Home

This project recreates the **“Find Your Dream House”** Figma design using **semantic HTML** and **Tailwind CSS**.
The goal is to reproduce the layout as closely as possible and implement a responsive version of the website.

---

## Project Overview

The website represents a **real estate landing page** where users can explore featured properties and learn about the services provided by the company.

The project also introduces a basic **team development workflow** using GitHub, Trello and Pull Requests.

---

## Selected Design

Our team selected the provided Figma design:

**Find Your Dream House**

The desktop layout serves as the primary reference.
Responsive behaviour will be implemented afterwards.

---

## Page Structure

The website is organised as a **single-page layout** with the following sections:

1. Header / Navigation
2. Hero Section
3. Search Bar
4. About / Statistics
5. Why Choose Us
6. Popular Residences
7. Testimonials
8. Contact / Call to Action
9. Footer

## Workflow

Project tasks are managed in **Trello**.

Task status is determined by the column in which the card is placed.

Planning → Design → Development → Review → Done

A task may only move to the next column when its checklist is completed.

---

## Branch Strategy

Development should not be done directly on the `main` branch.

Typical workflow:

1. Create a feature or docs branch from `main`
2. Implement the change
3. Push the branch
4. Open a Pull Request
5. Review and merge into `main`

Example branch names:

- `docs/add-readme`
- `feature/navbar`
- `feature/hero-section`
- `feature/property-cards`
